# 微信表情包一键导出（wechat-gif-export）

把 **Windows 电脑版微信 4.x** 里你收藏的表情包，一键导出成普通的 GIF / PNG / JPG 文件。导出的文件可以发到 X（Twitter）、Telegram、QQ 等任何地方。

> 微信 4.x 把表情包加密存在本地，以前那种「改后缀成 .gif」的方法已经不管用了。这个工具会自动解密并导出。

## 能做什么

- 双击一下就能用，不需要会编程
- 自动找到微信数据文件夹，包括挪到 D 盘等自定义位置的
- 自动识别当前登录的是哪个微信号，多个号分开导出
- 导出全部收藏的表情（经实测 549 个，95 秒）
- 把 GIF 动图单独挑出来，放进「只看GIF动图」文件夹
- 提醒超过 15MB 的 GIF（X 上发不了）
- 没装 Python 的话会自动安装

## 使用方法

1. 点右上角绿色的 **Code → Download ZIP**，下载后解压
2. 打开电脑版微信，**登录**
3. 双击 **`一键导出微信表情.bat`**
4. 等一两分钟，会自动弹出「只看GIF动图」文件夹

导出结果在 `导出结果\<你的微信号>\` 里：

```
导出结果\wxid_xxxxxx\
├── 只看GIF动图\     ← 所有 GIF 动图，001.gif、002.gif …
├── favorite\        ← 全部收藏表情（含静态图）
├── store\           ← 表情商店的表情（按包分组）
└── unknown\         ← 没匹配到信息的
```

> 第一次运行时如果提示「正在安装 Python」，装完关掉窗口再双击一次就行。

## 常见问题

**跑完是空的，或者提示出错？**
右键 `一键导出微信表情.bat`，选「以管理员身份运行」。微信如果是以管理员身份打开的，本工具也要用管理员身份运行。

**杀毒软件报毒？**
工具需要读取微信进程的内存来获取解密密钥，有些杀毒软件会因此拦截。代码全部开源，可以自行检查。

**只导出了一部分？**
收藏的表情要从微信服务器重新下载，需要联网。个别微信内置表情（骰子、石头剪刀布）导不出来，这是正常的。

**新版微信用不了？**
微信更新可能会改加密方式。遇到这种情况请开 Issue，并附上微信版本号。

## 原理

1. 读取正在运行的微信进程内存，拿到账号 seed，算出表情密钥：`md5(seed + wxid + "EMOTICON")`
2. 用 AES-128-CBC 解密本地表情文件
3. 解密 `emoticon.db`（SQLCipher 4），读出每个收藏表情的下载地址
4. 从微信 CDN 下载原图，把私有的 wxgf（HEVC）动图转成 GIF

全程只在你自己的电脑上处理。除了从微信服务器下载表情以外不联网，**不会上传任何数据**。
