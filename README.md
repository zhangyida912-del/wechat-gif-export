# 表情包一键导出（微信 + QQ + Telegram）

把 **Windows 电脑版微信 4.x**、**QQ（新版 QQNT）** 和 **Telegram** 里的表情包 / 贴纸，一键导出成普通的 GIF / PNG / JPG 文件。导出的文件可以发到 X（Twitter）、Telegram、QQ 等任何地方。

> 微信 4.x 把表情包加密存在本地，以前那种「改后缀成 .gif」的方法已经不管用了。这个工具会自动解密并导出。

## 能做什么

- 双击一下就能用，不需要会编程
- **微信**：导出全部收藏表情 + 聊天里发过 / 收到过的表情（加密的，工具会自动解密，动图自动转 GIF）
- **QQ**：导出收藏的表情 + 聊天里收到过的表情 + 别人当图片发来的 GIF（自动识别真实格式，去重）
- **Telegram**（可选）：导出收藏的贴纸、最近用过的贴纸、保存的 GIF，动画贴纸 / 视频贴纸自动转成 GIF
- 自动找到微信数据文件夹，包括挪到 D 盘等自定义位置的
- 自动识别当前登录的是哪个微信号，多个号分开导出
- 实测：微信导出 1200+ 个表情、900+ 个 GIF，两三分钟搞定
- 把 GIF 动图单独挑出来，放进「只看GIF动图」文件夹
- 提醒超过 15MB 的 GIF（X 上发不了）
- 没装 Python 的话会自动安装

## 使用方法

1. 点右上角绿色的 **Code → Download ZIP**，下载后解压
2. 要导出微信表情的话，先打开电脑版微信并**登录**（QQ 不需要打开）
3. 双击 **`一键导出表情包.bat`**
4. 等一两分钟，会自动弹出「导出结果」文件夹

```
导出结果\
├── 微信_wxid_xxxxxx\
│   ├── 只看GIF动图\     ← 所有 GIF 动图，001.gif、002.gif …
│   ├── favorite\        ← 全部收藏表情（含静态图）
│   ├── 聊天里的表情\     ← 聊天里发过 / 收到过、但没收藏的表情
│   ├── store\           ← 表情商店的表情（按包分组）
│   └── unknown\         ← 没匹配到信息的
├── QQ_12345678\
│   ├── 只看GIF动图\     ← 所有 GIF 动图（已去重）
│   ├── 收藏的表情\
│   ├── 聊天收到的表情\
│   └── 聊天图片里的GIF\  ← 别人当图片发来的动图（只取 GIF，不碰照片）
└── Telegram_用户名\
    ├── 只看GIF动图\
    ├── 收藏的贴纸\
    ├── 最近用过的贴纸\
    └── 保存的GIF\
```

### Telegram（可选，设置一次）

Telegram 电脑版的本地缓存是用登录密钥加密的，本工具**不去解密它**，而是走 Telegram 官方接口：

1. 打开 [my.telegram.org](https://my.telegram.org)，用手机号登录（验证码发在 Telegram App 里，不是短信）
2. 点 **API development tools**，随便填个名字创建，记下 `api_id` 和 `api_hash`
3. 双击 **`设置Telegram.bat`**，粘贴这两个值，再按提示输入手机号和验证码
4. 以后双击 `一键导出表情包.bat` 就会一起导出 Telegram 贴纸

> 国内需要开着代理（如 Clash）的「系统代理」，工具会自动使用。
> 设置后文件夹里会多出 `tg.session`，它就是你的 Telegram 登录状态，**不要发给任何人**。

> 第一次运行时如果提示「正在安装 Python」，装完关掉窗口再双击一次就行。

## 常见问题

**跑完是空的，或者提示出错？**
右键 `一键导出表情包.bat`，选「以管理员身份运行」。微信如果是以管理员身份打开的，本工具也要用管理员身份运行。

**杀毒软件报毒？**
工具需要读取微信进程的内存来获取解密密钥，有些杀毒软件会因此拦截。代码全部开源，可以自行检查。

**只导出了一部分？**
收藏的表情要从微信服务器重新下载，需要联网。个别微信内置表情（骰子、石头剪刀布）导不出来，这是正常的。

**抖音呢？**
抖音收藏的表情不存在电脑本地，只能联网从抖音服务器拉取（而且要过反爬签名），所以暂不支持。

**新版微信用不了？**
微信更新可能会改加密方式。遇到这种情况请开 Issue，并附上微信版本号。

## 原理

**QQ**：新版 QQ 的表情存在 `文档\Tencent Files\<QQ号>\nt_qq\nt_data\Emoji` 里，没有加密，只是 GIF 也用了 `.jpg` 后缀。工具按文件头识别真实格式后还原。（表情商店的表情加密了，暂不支持。）

**Telegram**：调用官方接口 `messages.getFavedStickers` / `getRecentStickers` / `getSavedGifs` 下载原文件；`.tgs` 动画贴纸用 rlottie 渲染成 GIF，`.webm` 视频贴纸和 MP4 GIF 用 ffmpeg 转成 GIF。

**微信**：

1. 读取正在运行的微信进程内存，拿到账号 seed，算出表情密钥：`md5(seed + wxid + "EMOTICON")`
2. 用 AES-128-CBC 解密本地表情文件
3. 解密 `emoticon.db`（SQLCipher 4），读出每个收藏表情的下载地址
4. 从微信 CDN 下载原图，把私有的 wxgf（HEVC）动图转成 GIF
5. 聊天里出现过的表情缓存在 `cache\年-月\Emoticon`，用同一把密钥解密，跳过和收藏重复的

全程只在你自己的电脑上处理。除了从微信服务器下载表情以外不联网，**不会上传任何数据**。
